# Third-party components

The generated `viewer.js` bundles these browser libraries:

- `@carbonplan/zarr-layer` 0.11.0 — MIT
- `zarrita` 0.7.x — MIT
- `proj4` 2.22.0 — MIT
- `@developmentseed/raster-reproject` 0.7.0 — MIT
- `delaunator` 5.x — ISC

`geolibre_wasm_bg.wasm` is from `geolibre-wasm` 1.5.8, published by the
GeoLibre project under the MIT license. It provides the client-side Cloud
Optimized GeoTIFF encoder.

The source projects and their license texts are available through their npm
package metadata and upstream repositories.

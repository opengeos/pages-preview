opengeos pull-request previews

Machine-generated preview builds for open pull requests across opengeos repositories. Nothing here is production.

Each preview lives at a path built from the repository name and PR number:

https://opengeos.org/pages-preview/<repo-name>/pr-<number>/

There is no index of live previews — open one from the preview link posted on its pull request. Previews are rebuilt on every push and removed when the pull request closes.

Previews run unreviewed code A preview is built from a contributor's branch and runs in your browser with no review gate. Open one only for a pull request you are reviewing, and prefer a throwaway browser profile.
Setup, deploy-token, and housekeeping notes live in the repository README.

project¶

Builders for GeoLibre project (.geolibre.json) dicts and their layers.

The shapes here mirror the TypeScript interfaces in packages/core/src/types.ts and packages/core/src/project.ts. Keeping the Python builders faithful to those interfaces is what lets the embedded app load a project produced entirely from Python.

LIDAR_SOURCE_KIND module-attribute ¶

LIDAR_SOURCE_KIND = 'lidar-url'

metadata.sourceKind of a LiDAR point cloud the app streams from a URL.

POINT_CLOUD_ANNOTATION_PLUGIN_ID module-attribute ¶

POINT_CLOUD_ANNOTATION_PLUGIN_ID = 'geolibre-point-cloud-annotation'

Plugin id under which the app saves point cloud labels and 3D boxes.

MAX_POINT_LABEL_NODE_BYTES module-attribute ¶

MAX_POINT_LABEL_NODE_BYTES = 16 * 1024 * 1024

Largest inflated size of one node's saved labels (mirrors the app's cap).

MAX_POINT_LABEL_BYTES module-attribute ¶

MAX_POINT_LABEL_BYTES = 256 * 1024 * 1024

Largest total inflated size of all saved labels in one project.

MAX_POINT_LABEL_EDITS module-attribute ¶

MAX_POINT_LABEL_EDITS = 20000000

Most decoded label entries across a project; bounds Python memory, since a dict entry costs far more than the two inflated bytes behind it.

CUSTOM_CLASS_MIN module-attribute ¶

CUSTOM_CLASS_MIN = 19

Lowest code a custom class may use (ASPRS reserves 19-63, 64-255 are user).

CUSTOM_CLASS_MAX module-attribute ¶

CUSTOM_CLASS_MAX = 255

Highest code a custom class may use (the LAS classification byte).

CESIUM_ION_SOURCE_KIND module-attribute ¶

CESIUM_ION_SOURCE_KIND = 'cesium-ion'

metadata.sourceKind of a layer that references a Cesium Ion asset.

CZML_SOURCE_KIND module-attribute ¶

CZML_SOURCE_KIND = 'czml'

metadata.sourceKind of a layer that references a CZML dynamic scene.

redact_url ¶

redact_url(url: str) -> str

Return a URL with its userinfo and credential parameters stripped.

The public entry point to the sweep redact_credentials applies to every URL it finds, for the single-value reads (Map.basemap) that hand one back rather than writing a whole project out.

redact_layer_field ¶

redact_layer_field(value: Any) -> Any

Return one of a layer's config fields, detached and swept.

The single-field counterpart to redact_layer, for a read that wants only source and should not pay to copy an inlined GeoJSON blob first.

redact_layer ¶

redact_layer(layer: dict[str, Any]) -> dict[str, Any]

Return a detached copy of one layer, safe to display or hand to others.

The same sweep redact_credentials applies to every layer, for the single-layer reads (Layer.source, Layer.data) that hand a layer record back to a caller rather than writing a whole project out.

apply_tooltip ¶

apply_tooltip(config: dict[str, Any], tooltip: Any) -> dict[str, Any]

Fold a tooltip= shorthand into a popup config, in place.

The app's hover tooltip needs two things: hover on the config, and at least one field flagged hover (or a configured title) to put in it -- createHoverTooltipElement returns nothing otherwise. This raises the field flags, then checks the finished config through _assert_tooltip_can_render so a tooltip that could never appear is an error however hover was switched on.

Parameters:

Name Type Description Default
config dict[str, Any]

The popup config being built (mutated in place).

 required
tooltip Any

True/False to flag every configured field or turn the tooltip off, or a property name or sequence of names to flag. An empty sequence means the same as False. Note that naming a field here adds it to fields, and a non-empty fields is also what the click popup shows -- so a tooltip field on a popup that had no field list narrows the click popup to it.

 required

Returns:

Type Description
dict[str, Any]

The same config.

Raises:

Type Description
ValueError

If a tooltip field name is blank, or the finished config leaves the tooltip on with nothing to show.

wms_layer ¶

wms_layer(name: str, endpoint: str, layers: str, *, styles: str = '', image_format: str = 'image/png', transparent: bool = True, tile_size: int = 256, version: str | None = '1.1.1', crs: str | None = None, bounds: list[float] | None = None, **style: Any) -> dict[str, Any]

Build a WMS layer rendered as tiled raster (a WMS GetMap request).

The GetMap tile template is built exactly as createWmsTileUrl in the Add Data dialog, so the core raster sync renders it identically to a layer added through the UI. The {bbox-epsg-3857} placeholder is substituted per tile.

Parameters:

Name Type Description Default
name str

Layer display name.

 required
endpoint str

WMS service endpoint (the GetMap base URL).

 required
layers str

Comma-separated WMS layer name(s).

 required
styles str

Comma-separated WMS style name(s) (empty for the default).

 ''
image_format str

WMS image format (e.g. "image/png").

 'image/png'
transparent bool

Whether to request transparent tiles.

 True
tile_size int

Tile size in pixels.

 256
version str | None

WMS protocol version, "1.1.1" (default) or "1.3.0". Version 1.3.0 sends CRS instead of SRS; some servers accept only one version. EPSG:3857 keeps its axis order in both, so the BBOX template is unchanged. None falls back to "1.1.1".

 '1.1.1'
crs str | None

The CRS tiles are requested in: "EPSG:3857" (None, the default) or, for a server that does not offer Web Mercator, a CRS it does list in its capabilities: a geographic one ("EPSG:4326", "EPSG:4258", "EPSG:6706", "CRS:84") or a projected "EPSG:<code>" such as "EPSG:25832". The desktop app requests each tile's extent in that CRS and redraws or warps it into Web Mercator; the web build still sends the Web Mercator BBOX, which such a server rejects.

 None
bounds list[float] | None

Optional [west, south, east, north] request bounds, in WGS84. Take them from the service's EX_GeographicBoundingBox, which is always lon/lat, rather than a 1.3.0 BoundingBox CRS="EPSG:4326", whose axis order servers often get wrong.

 None
**style Any

Style overrides merged into the default layer style.

 {}

Returns:

Type Description
dict[str, Any]

A layer dict for the project's layers array.

Raises:

Type Description
ValueError

If bounds is not four finite numbers with valid latitudes, crs is neither one of WMS_CRS nor an EPSG:<code>, or crs is "CRS:84" with a version other than 1.3.0.

bookmark(name: str, *, center: tuple[float, float] | list[float], zoom: float, pitch: float = 0, bearing: float = 0, group_id: str | None = None, visible_layer_ids: list[str] | None = None, bookmark_id: str | None = None, created_at: int | None = None) -> dict[str, Any]

Build one saved map view for the Bookmarks panel (ProjectBookmark).

Values are stored the way normalizeBookmarks in project.ts leaves them, so the app loads the bookmark unchanged: the bearing is wrapped into 0-360, and out-of-range coordinates, zooms, and pitches are refused rather than silently clamped.

3. Cloud-Native Formats: COG, GeoParquet, PMTiles, and Zarr¶

10:00 - 11:00 a.m.

Lecture 20 min · Hands-on 30 min · Break 10:50 - 11:00

Learning goals¶

  • Explain how each cloud-native format lets a client read only what it needs.
  • Load and style a Cloud-Optimized GeoTIFF (COG).
  • Stream a GeoParquet file without copying it into memory.
  • Load a PMTiles archive and a Zarr data cube.
  • Choose the right format for a given task.

Lecture (20 min)¶

The common trick: an index up front¶

Every cloud-native format does the same two things: it puts an index (metadata) where a client can read it with one small request, and it chunks the data so each request returns a useful piece.

Format Data type Index Chunk Typical use
COG (Cloud-Optimized GeoTIFF) Raster TIFF header with tile offsets, plus overviews (reduced-resolution copies) 256 or 512 px tiles Imagery, elevation, land cover
GeoParquet Vector table Parquet footer: schema, row groups, column statistics, bounding boxes Row group × column Large tables to filter, aggregate, and join
FlatGeobuf Vector features Packed Hilbert R-tree Feature Streaming features by bounding box
PMTiles Pre-rendered vector or raster tiles Directory of tile offsets One map tile (z/x/y) Basemaps and fast cartographic display
Zarr N-dimensional arrays .zmetadata or zarr.json Array chunk (e.g. time × lat × lon) Climate, weather, ocean model output
COPC / EPT Point clouds Octree hierarchy Octree node LiDAR (Section 6)

A COG viewed at a small scale reads only an overview, a few hundred kilobytes, even if the full-resolution file is gigabytes. A GeoParquet query reads the footer, skips row groups whose bounding boxes miss the area of interest, and reads only the columns the query needs.

Which format when?¶

  • Display a large raster: COG.
  • Analyze a large table with SQL: GeoParquet.
  • Pan around a big vector layer quickly at every zoom: PMTiles (the geometry is simplified per zoom level, so it is for display, not analysis).
  • Slice a variable through time or depth: Zarr.

How the workshop data was made¶

Every file in the workshop bucket came from the same Census counties shapefile, converted with standard open tools:

ogr2ogr -f FlatGeobuf us_counties.fgb cb_2023_us_county_500k.shp -t_srs EPSG:4326
ogr2ogr -f Parquet us_counties.parquet us_counties.fgb \
  -lco COMPRESSION=ZSTD -lco SORT_BY_BBOX=YES -lco WRITE_COVERING_BBOX=YES
ogr2ogr -f PMTiles us_counties.pmtiles us_counties.fgb -dsco MAXZOOM=10
gdalwarp -of COG -co COMPRESS=DEFLATE -co OVERVIEWS=AUTO dem.vrt reno_tahoe_dem.tif

GeoLibre can do the same conversions in the browser with Processing → GeoLibre toolbox → Conversion (Vector to GeoParquet, Vector to FlatGeobuf, Vector to PMTiles, Raster to COG).

Hands-on (30 min)¶

Start a new project: Project → New..., name it NGIS 2026 - 3 Cloud-native formats, pick the Positron basemap, and click Create.

Exercise 3.1: A Cloud-Optimized GeoTIFF (8 min)¶

  1. Add data → Raster layer. Leave the rendering engine at cog-tiler-wasm (WASM).

  2. Paste the URL and click Load:

    https://assets.geolibre.app/data/workshops/ngis-2026/reno_tahoe_dem.tif

  3. The map zooms to the Reno-Tahoe area. Close the Add Raster Layer panel.

  4. In the Style panel, open Color ramp and choose terrain. The histogram below the ramp shows the elevation range, about 1,300 to 3,300 m.
  5. The DEM is 2520 × 3240 pixels and 22 MB, yet it appeared almost instantly: the browser fetched only the overview tiles it needed for the current view.
  6. Use Inspect pixel values on the layer row and click Mount Rose (northeast of Lake Tahoe) to read its elevation.

Discussion

Lake Tahoe shows as a flat area at about 1,897 m. Why does the terrain ramp paint some low valleys blue as if they were water?

Exercise 3.2: Stream a GeoParquet file (8 min)¶

  1. Add data → GeoParquet layer.

  2. Tick Stream GeoParquet (no copy). Paste the URL and click Load:

    https://assets.geolibre.app/data/workshops/ngis-2026/us_counties.parquet

  3. The panel lists the layer as geoparquet · 3.2k ft · geojson · stream. The file is read in place with HTTP range requests instead of being copied into memory.

  4. The map zooms out to the full extent, which spans Guam to the Aleutians. Type Nevada in the search box and pick Nevada, United States, then zoom out a few steps.
  5. Open View → Set view... to type an exact camera if you overshoot.

Streaming or not?

Streaming suits large, spatially sorted files. This file was written with SORT_BY_BBOX, so nearby counties sit in the same row groups. For small files, leave streaming off: you get the full Style panel and the attribute table.

Exercise 3.3: PMTiles (7 min)¶

  1. Hide the us_counties layer (eye icon).

  2. Add data → PMTiles layer. Paste:

    https://data.source.coop/giswqs/opengeos/building_count_h3.pmtiles

  3. Click Fetch. The dialog finds one source layer, data. Set Layer Name to Building counts (H3, PMTiles) and click Add Layer.

  4. In the Style panel choose Style type: Graduated, Attribute: building_count, Scheme: Quantile, and click Apply style type. Under Outline color, tick Transparent.
  5. Zoom in and out. Each zoom level requests a handful of tiles from a single archive file, with no tile server involved.

Exercise 3.4: Zarr (7 min)¶

  1. Hide the PMTiles layer.
  2. Add data → Zarr layer. Open Load sample data... and pick Sea surface temperature, monthly (NOAA). The form fills in the URL, the variable sst, and a display range of -2 to 32 °C.
  3. Tick Pickable (click to show pixel value), set Layer Name to Sea surface temperature (Zarr), and click Add Layer.
  4. Zoom out to a global view and click the ocean to read temperatures.
  5. Change Selector (JSON) to pick another time step, for example {"time": 12}, and add it as a second layer. Toggle between them.

A 404 in Diagnostics is expected

The Zarr reader first checks for a Zarr v3 zarr.json. This store is Zarr v2, so that check returns 404 and the reader falls back to .zmetadata. The Diagnostics counter in the status bar records the 404; it is harmless.

Save the project.

Check your work¶

Open the finished project

The finished project opens on the counties with the PMTiles and Zarr layers hidden. Toggle them on in the Layers panel.

Going further¶

  • Open your browser's developer tools (F12), go to the Network tab, and pan the COG. Look for 206 Partial Content responses with a Range header.
  • Convert a file of your own with Processing → GeoLibre toolbox → Conversion.
  • Browse more cloud-native datasets with Plugins → Web services → Source Cooperative.
  • Read Cloud-Native Data and Supported Data Formats.

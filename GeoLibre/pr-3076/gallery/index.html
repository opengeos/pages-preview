Gallery¶

105 interactive maps built from public open data, grouped by theme. Each is a single .geolibre.json project authored with the Python package and shared on share.geolibre.app: choropleths, heatmaps, clusters, great-circle flows, 3D extrusions, before-and-after swipes, and time sliders, with click popups, hover tooltips, and a legend derived from each layer's symbology. Click any map to open the live project, or fork it on share.geolibre.app to make it your own.

Every project is tagged with its theme, its features (time-slider, swipe, 3d, heatmap, clusters, imagery), and open-data, so you can filter the gallery on share.geolibre.app by tag.
